# HomeSolarPH

A free, neutral resource for Philippine homeowners deciding whether to go rooftop solar.

**Status:** planning. No application code yet.

Stage 1 (test app) features:
- **Solar check:** basic sizing, savings and payback ranges from a few bill and roof details.
- **Installer guide:** questions to ask, red flags, and process steps.
- **Quote comparison:** upload installer quotes, confirm the extracted figures, and compare them side by side.
